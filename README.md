# Firebot RPG Custom Script

## What is this?

Firebot RPG is a custom script created to be used in Firebot. Firebot is a Twitch bot created by Team Crowbar. This script is not made for use outside of Firebot, including other bots or standalone.

The version is forked by Brett Slaski from [https://github.com/itsjesski/firebot-rpg](https://github.com/itsjesski/firebot-rpg) (which may have previously been Firebottle) to continue work on the project. There haven't been any updates in over four years.
