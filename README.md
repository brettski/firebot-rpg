# Firebot RPG Custom Script

Firebot RPG is an RPG game meant to be played via a live stream chat interface. Because of this, Firebot RPG was built to be as simple as possible to control via chat commands, while hiding most of the complex mechanics in the script's backend. For the most part, this script plays like D&D. You'll be familiar with weapon damage rolls and other pieces, but some rules have been simplified (yes, even more than 5th edition).

## What is this?

Firebot RPG is a custom script for use in Firebot. [Firebot](https://firebot.app/) is a Twitch bot created by Team Crowbar. This script is not made for use outside of Firebot, including other bots or standalone use.

This version (v1.1.0+) is a fork by Brett Slaski of [https://github.com/itsjesski/firebot-rpg](https://github.com/itsjesski/firebot-rpg) (which may have previously been Firebottle) to continue work on the project. There haven't been any updates in over four years.
